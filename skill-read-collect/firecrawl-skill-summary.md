# Firecrawl 技能说明汇总

## 1. 功能

这个技能的核心作用是通过 Firecrawl CLI 提供一套面向网页内容获取的能力，主要包括：

- 网页搜索：在用户还没有明确 URL 时，根据关键词搜索网页。
- 网页抓取：对指定 URL 提取页面内容，输出适合大模型处理的 Markdown。
- 站点映射：在一个网站内部查找目标页面或路径。
- 站点爬取：批量抓取某个网站或文档区域的多页内容。
- 浏览器自动化：处理需要点击、翻页、登录、填写表单等交互后才能获取内容的页面。
- AI 结构化提取：从复杂网页中抽取结构化信息。
- 整站下载：把网站内容保存为本地文件。

简单说，这个技能适合用在“上网找资料、抓网页内容、抓文档站、处理需要交互的网站”这类任务上。

## 2. 用什么技术或能力实现

这个技能主要依赖以下技术和能力实现：

- Firecrawl CLI：这是底层执行工具，负责搜索、抓取、爬取和浏览器自动化。
- 命令行调用：技能通过 Bash 命令触发 `firecrawl` 或 `npx firecrawl` 来执行任务。
- 云端/远程浏览器能力：用于处理普通抓取拿不到内容的网页，例如需要点击、登录、分页或动态加载的页面。
- Markdown 输出能力：抓取结果会优先整理成适合大模型消费的 Markdown，方便后续总结、翻译、分析。
- 文件化结果管理：支持把结果写入 `.firecrawl/` 目录，便于后续读取、筛选和复用。
- 并行处理能力：说明中明确支持并发抓取多个页面，以提升批量任务效率。

从能力层面看，它本质上是把“网页搜索 + 内容抓取 + 浏览器自动化 + 结构化提取”封装成一个可复用技能。

## 3. 我可以如何触发使用这个技能

当你的需求属于以下场景时，就可以触发这个技能：

- 想搜索某个主题的网页资料。
- 想抓取某个 URL 的正文内容。
- 想从一个网站里找某个特定子页面。
- 想批量下载一个文档站或网站栏目。
- 想提取网页里的结构化数据。
- 想操作一个需要点击、登录、翻页后才能看到内容的页面。

技能说明里给出的典型触发说法包括：

- “搜索一下这个主题”
- “帮我找几篇相关文章”
- “看看这个网址的内容”
- “抓取这个页面”
- “提取这个网站的数据”
- “爬一下这个文档站”
- “下载这个网站”
- “打开这个页面并点击后把内容抓出来”
- “fetch this page”
- “pull the content from ...”
- “get the page at https://...”

同时，这个技能也明确了不适合触发的场景：

- 本地文件操作
- Git 命令
- 部署任务
- 普通代码编辑任务

## 补充理解

这个技能的使用路径是分层升级的：

1. 没有 URL 时先用搜索。
2. 已知 URL 时先用抓取。
3. 一个站点里找页面时用映射。
4. 批量抓站点时用爬取。
5. 抓不到或需要交互时再用浏览器自动化。

这意味着它不是单一“爬虫命令”，而是一整套面向网页信息获取的工作流技能。
